# AI Tech Stack Recommender

An AI-powered recommendation system that suggests the most relevant technology career paths based on a user’s skills. The project uses **TF-IDF Vectorization** and **Cosine Similarity** to compare user skills with job-role requirements and generate the top career recommendations.

---

## Project Overview

This project demonstrates a **content-based recommendation system** built using Python and Scikit-learn. Users enter three skills, and the system analyzes a dataset of technology roles and required skills to recommend the most suitable career paths.

The recommendation engine converts text into numerical vectors using **TF-IDF (Term Frequency–Inverse Document Frequency)** and calculates similarity scores using **Cosine Similarity**.

---

## Features

* Accepts user skill input
* Reads job-role data from a CSV dataset
* Uses **TF-IDF Vectorization**
* Calculates **Cosine Similarity**
* Displays the **Top 3 career recommendations**
* Shows recommendation match percentages
