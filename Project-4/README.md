# AI Face Detection App

An AI-powered face detection application that identifies human faces in uploaded images using a pre-trained OpenCV Haar Cascade model. The project uses **OpenCV** for image processing and **Streamlit** to create an interactive web application where users can upload an image and detect faces automatically.

---

## Project Overview

This project demonstrates a **computer vision-based face detection system** built using Python and OpenCV. Users upload an image, and the application processes it to detect human faces and draw bounding boxes around them.

The face detection model uses **OpenCV’s Haar Cascade Classifier**, a pre-trained machine learning model designed for efficient face detection in images.

---

## Features

* Uploads JPG and PNG images
* Detects human faces using a **pre-trained Haar Cascade model**
* Draws bounding boxes around detected faces
* Displays the **total number of faces detected**
* Interactive and user-friendly **Streamlit interface**
